# SkillOps

SkillOps is a maintenance and governance discipline for agent skill repositories. It focuses on validation, metadata, quality, lifecycle, documentation, and future evaluation of reusable skills.

SkillOps is inspired by package management, DevOps, and MLOps patterns. The goal is to make skill repositories understandable, reviewable, and maintainable as they grow.

In Phase 1, `skillops` is a repository foundation with schemas, a registry, core validation logic, CLI commands, core skills, agent setup, documentation, and LLM-Wiki pages. It should not be described as a complete future marketplace, future observability system, or future automated self-improvement platform.
