# Skill-TDD

Skill-TDD is the planned SkillOps workflow of writing or updating representative skill behavior scenarios before changing a skill implementation.

In the current Phase 2 foundation, Skill-TDD is limited to Golden Sets plus local-first Promptfoo smoke configuration, with broader execution planned later:

- define golden cases for expected skill behavior
- keep case categories explicit
- connect each core skill to one draft eval suite
- map Golden Set expectations to deterministic Promptfoo assertions while broader execution is planned later
- validate that files and references are consistent

DeepEval execution, mandatory CI smoke evaluation gates, and richer automated Skill-TDD reporting are planned for later Phase 2 packages and are not implemented here.
