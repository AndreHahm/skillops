# Skill-TDD

Skill-TDD is the planned SkillOps workflow of writing or updating representative skill behavior scenarios before changing a skill implementation.

In Phase 2 Package 1, Skill-TDD is limited to static metadata:

- define golden cases for expected skill behavior
- keep case categories explicit
- connect each core skill to one planned eval suite
- validate that files and references are consistent

Promptfoo execution, DeepEval execution, CI smoke evaluation commands, and richer automated Skill-TDD reporting are planned for later Phase 2 packages and are not implemented here.
