# SkillOps Evaluation Foundation

This directory contains the Phase 2 Package 1 evaluation foundation for SkillOps. It stores static evaluation metadata and seed scenarios only.

Implemented in this package:

- evaluation directory structure
- golden set schema
- initial golden sets for the five Phase 1 core skills
- eval suite schema
- eval suite registry
- consistency tests

Planned for later Phase 2 packages, and not implemented here:

- Promptfoo configuration and execution
- DeepEval tests and execution
- CI smoke evaluation command
- richer Skill-TDD workflow
- production observability, dependency graph behavior, marketplace behavior, and self-improvement automation

The files in this directory are not runtime outputs. They are reviewed seed data and metadata for future evaluation execution work.
