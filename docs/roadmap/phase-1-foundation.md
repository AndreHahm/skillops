# Phase 1 Foundation

## Goal

Phase 1 establishes the repository foundation for `skillops`: schemas, registry files, core validation logic, CLI workflows, core skills, agent setup, documentation, and LLM-Wiki knowledge.

## Packages

1. Foundation / repository bootstrap.
2. Schema & Registry.
3. Core Library.
4. CLI MVP.
5. Core Skills.
6. Agent Setup.
7. Docs & LLM-Wiki.
8. CI Foundation.

## Completed Foundation Areas

The repository currently contains the Phase 1 schema and registry foundation, reusable core package, CLI MVP, five core skills, agent setup files, hook examples, MCP examples, documentation pages, LLM-Wiki pages, and CI foundation configuration.

## Package 8: CI Foundation

Package 8 establishes the Phase 1 CI workflow, local just commands, markdownlint configuration, repository structure checks, and GitHub contribution templates.

It does not implement release automation, deployment automation, marketplace publication, or evaluation integrations.

## Remaining Phase 1 Areas

Phase 1 foundation package configuration is present. Repository checks and documentation should still be kept aligned as changes are made.

## Out of Scope

Phase 1 does not include full marketplace mechanics, dependency graph generation, Promptfoo integration, DeepEval integration, Langfuse or Phoenix observability integration, third-party skill sync, self-improvement automation, release automation, deployment automation, database support, or a web UI.

## Definition of Done

Phase 1 is done when the planned foundation packages are implemented, validation and tests pass, documentation reflects actual behavior, and future features remain clearly labeled as planned or out of scope.
